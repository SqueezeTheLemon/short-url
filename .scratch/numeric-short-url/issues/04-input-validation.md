# 04: 입력 검증과 에러 표시

**What to build:** 서버는 유효한 http/https 원본 URL만 받아들이고, 그렇지 않으면 이유를 담은 `400`을 응답한다. 익명 방문자는 화면에서 무엇이 잘못됐는지 한국어 메시지로 본다. 받아들인 원본 URL은 정규화된 형태로 저장되어, 리디렉션 시 경로·쿼리·프래그먼트가 유지된다. (ADR-0005)

**Blocked by:** 01 (최소 관통: 생성하고 이동하기)

**Status:** ready-for-agent

- [ ] 앞뒤 공백을 제거한 뒤 파싱하며, scheme이 http/https가 아니면 `400 { "error": ... }`를 응답한다 (예: `javascript:`, `ftp://`)
- [ ] host가 없는 URL, 2048자를 넘는 URL, 파싱할 수 없는 문자열은 `400`을 응답한다
- [ ] origin이 `PUBLIC_ORIGIN`과 같은 URL(이 서비스 자신의 단축 주소)은 `400`을 응답한다
- [ ] 원본 URL은 `url` crate로 정규화한 문자열로 저장된다
- [ ] 경로·쿼리·프래그먼트가 있는 원본 URL로 만든 링크가 리디렉션 시 이를 모두 유지한다
- [ ] 화면이 서버의 에러 메시지를 사용자에게 보여준다
- [ ] 위 규칙이 모두 seam ① 통합 테스트로 검증된다
