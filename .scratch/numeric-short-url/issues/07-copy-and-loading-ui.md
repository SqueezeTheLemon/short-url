# 07: 화면 다듬기 (복사, 로딩)

**What to build:** 익명 방문자가 생성된 단축 주소를 버튼 한 번으로 복사하고 "복사됨!" 피드백을 본다. 생성 요청이 진행되는 동안에는 버튼이 비활성화되어 같은 요청이 여러 번 나가지 않는다.

**Blocked by:** 01 (최소 관통: 생성하고 이동하기)

**Status:** ready-for-agent

- [ ] 결과 단축 주소 옆에 복사 버튼이 있고, 누르면 단축 주소 전체가 클립보드에 담긴다
- [ ] 복사 성공 시 "복사됨!" 피드백이 잠시 보인다
- [x] 복사에 실패하면(예: 비보안 컨텍스트) 사용자가 알 수 있는 메시지가 보인다
- [x] 생성 요청 중에는 생성 버튼이 비활성화되고 진행 중임이 보인다
- [ ] localhost와 HTTPS 공개 주소 양쪽에서 복사가 동작한다
