# 05: 404 처리

**What to build:** 존재하지 않는 번호나 형식에 맞지 않는 번호로 접속한 사람은 서버가 응답하는 `404`와 함께 알아볼 수 있는 HTML 안내 페이지를 본다. 한 번호는 선행 0 없는 십진수 한 가지 표기만 갖는다. 숫자가 아닌 경로에서는 Dioxus 화면의 "페이지 없음" 안내를 본다.

**Blocked by:** 01 (최소 관통: 생성하고 이동하기)

**Status:** ready-for-agent

- [ ] 존재하지 않는 번호는 `404`와 HTML 안내 페이지를 응답한다
- [ ] 선행 0(`/0123`), `/0`, i64 범위를 넘는 수는 존재 여부와 관계없이 `404`와 같은 안내 페이지를 응답한다
- [ ] 안내 페이지에서 사람이 "주소가 잘못됐다"는 것과 홈으로 돌아가는 방법을 알 수 있다
- [ ] 숫자가 아닌 미지의 경로는 Dioxus 라우터의 "페이지 없음" 화면을 보여준다
- [ ] 백엔드 404 규칙이 seam ① 통합 테스트로 검증된다
