# 06: 링크 무결성 (불변성, 동시성, 영속성)

**What to build:** 링크는 한 번 만들어지면 누구도 바꾸거나 지울 수 없다. 서버는 링크 수정·삭제 요청을 거부하고, 애플리케이션 코드를 우회하더라도 DB가 변경을 거부한다. 여러 사람이 동시에 서로 다른 URL을 생성해도 번호가 겹치거나 기존 링크가 덮어써지지 않으며, 서버를 다시 띄워도 링크가 유지된다. 같은 원본 URL을 다시 넣으면 새 번호가 발급된다. (ADR-0002)

**Blocked by:** 01 (최소 관통: 생성하고 이동하기)

**Status:** ready-for-agent

- [x] 링크 경로에 대한 `PUT`/`PATCH`/`DELETE` 요청은 `405`를 응답하고 링크는 그대로다
- [x] DB 트리거가 링크 테이블의 `UPDATE`/`DELETE`를 거부하며, 마이그레이션으로 적용된다
- [x] seam ② 테스트가 앱을 거치지 않은 SQL `UPDATE`/`DELETE`가 거부됨을 검증한다
- [x] seam ① 테스트가 서로 다른 URL 50개를 동시에 생성해 번호가 모두 다르고 각 번호가 자기 원본 URL로 리디렉션됨을 검증한다
- [x] seam ① 테스트가 같은 DB로 앱을 새로 띄운 뒤 기존 링크가 같은 원본 URL로 리디렉션됨을 검증한다
- [x] seam ① 테스트가 같은 원본 URL을 두 번 생성하면 서로 다른 번호가 나옴을 검증한다
